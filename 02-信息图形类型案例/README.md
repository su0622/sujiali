## 更新原则
每增加一个案例，先写案例分析报告，再从证据中更新对应说明文档。说明文档应归纳信息框架、叙事方式、统计图形、符号体系、视觉编码、制作原则与局限。未经案例验证的通用建议标注为工作假设。
