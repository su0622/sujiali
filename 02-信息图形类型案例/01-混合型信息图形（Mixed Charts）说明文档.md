# 混合型信息图形（Mixed Charts）说明文档

> 类型定位：以统计图形为定量骨架，再通过符号系统、ISO 风格图形、插画、地图、注释和版式叙事把统计关系转译成面向阅读的视觉故事。它不等同于把两个标准图表简单拼在一起。

## 1. 概念与边界
混合型信息图形通常同时存在：
- **统计表达层**：条形、折线、比例符号、散点、排名等，承担数量、趋势、分布或比较。
- **符号 / 图示层**：图标、ISO 风格人物/物件符号、示意图、地图或结构图，承担对象识别、情境和分类。
- **叙事编排层**：标题、重点标注、引导线、分区、阅读顺序和文字解释，建立信息之间的关联。

关键判断：统计图形是信息论证的一部分，而非纯装饰；符号和版式进一步解释“这些数字意味着什么”。

## 2. 数据逻辑
先定义分析单位、指标、维度、比较口径和来源，再判断哪些字段适合统计编码，哪些适合符号或文字说明。常见结构包括分类×指标、时间×指标、空间实体×指标，以及实体—属性—关系的混合数据。

## 3. 统计图形与计算
可组合条形/折线/点图/比例符号/地图等，但每种图形必须对应明确变量。常见计算包括总量、占比、排名、变化率、均值、密度和分组汇总。组合前统一单位、时间范围、分母和统计粒度；不可把不同量纲共用一个视觉尺度。

## 4. 视觉编码原则
- 点：定位单个对象或事件。
- 线：连接、趋势、路径或引导；必须明确语义，不能让引导线被误读为流向。
- 面 / 体：表达区域、构成或数量时需说明面积/体积映射规则。
- 符号 / ISO 图形：建立对象类别和数量单位的直观识别；图标重复计数时须确保每个符号代表固定数量。
- 色彩：用于类别、强弱或重点，不要同时承担过多语义。
- 文字：直接标注关键值、单位和来源，降低纯视觉估读误差。

## 5. 信息架构与视觉叙事
建议采用“问题 / 结论先行 → 主统计图形 → 符号化解释 → 细节比较 → 来源与口径”的结构。叙事可以是极值吸引、对比、趋势推进、空间定位或因果链（仅在证据支持时）。

## 7. 制作流程与检查
1. 确定叙事问题和关键结论。
2. 建立数据字典、统计口径和数据表。
3. 为每个变量选择统计图形或符号编码。
4. 规划统计层、图示层、文本层的视觉层级。
5. 建立阅读路径，避免装饰符号与数据标记混淆。
6. 校验单位、比例、标签、图例、色彩对比及可访问性。
7. 保存源数据、基础图形、最终版和来源记录。

## 8. 持续更新
新增案例时记录：统计图形组合方式、符号体系、ISO 图形是否存在、编码映射、叙事顺序、计算口径、有效策略与失败点。至少有两个不同案例后，再归纳稳定原则；单个案例只记录为案例观察。
