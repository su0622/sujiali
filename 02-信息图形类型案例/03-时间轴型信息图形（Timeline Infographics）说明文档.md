# 时间轴型信息图形（Timeline Infographics）说明文档

> 类型定位：时间轴型是以时间为主导视觉骨架的表达形式。它与“编年型数据逻辑”高度相关，但时间轴也可用于项目计划、事件比较、生命周期和未来路线图；两者不能简单视为完全同义。

## 1. 核心数据逻辑
基本记录为事件或时间区间，至少包含时间字段和事件说明。常见字段：开始时间、结束时间、事件名称、主体、类别、阶段、持续时间、重要性和来源。时间可为离散日期、连续区间或相对阶段。

## 2. 统计图形与计算
可借用时间序列折线图（数值随时间变化）、甘特图（任务持续区间）、事件带 / 里程碑图（离散事件）和多泳道时间轴（多主体并行）。可计算持续时间、事件间隔、变化率、累计量和阶段跨度。若只讲事件顺序，不应伪造数值曲线。

## 3. 视觉编码
- 线：主时间轴，表达连续时间方向。
- 点：事件、里程碑或转折。
- 面 / 色带：时期、阶段或持续区间。
- 箭头：时间方向；若存在回溯或循环，应显式标注。
- 图标：事件类型或主体。
- 色彩：区分阶段 / 主体 / 事件类别；避免仅靠颜色编码时间顺序。
- 长度 / 间距：只有在时间尺度真实时才可按比例；编辑式排布须标注“非比例时间轴”。

## 4. 信息架构
时间范围与刻度 → 主时间轴 → 阶段分区 → 事件节点与注释 → 影响 / 结果。多主体案例可采用泳道；事件密集时可分层或分段，保持时间对应关系清楚。

## 5. 视觉叙事
通常由起点建立背景，沿时间推进，突出关键转折，再呈现结果或未来节点。通过节点大小、颜色或注释突出重要事件时，必须解释强调规则，不能让视觉显著性被误读为时间长短或数据规模。

## 6. 案例证据状态

## 7. 制作与检查
核对日期、时区、事件来源、时间粒度、重叠区间、标签密度、阅读方向、时间比例尺和无障碍文本说明。
