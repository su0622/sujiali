## 目录规则
- 本目录只放类型定义、原则、方法和案例文本链接，不保存案例图片，也不复制案例图。
- 每个案例报告保存在案例目录；在本目录文档的“案例证据与交叉链接”中用相对链接引用。
- 将内容区分为**案例观察**、**由多个案例归纳的原则**、**待案例验证的工作假设**。
- 只有单个案例时，不把个案特征写成普遍规律；案例增加后记录共性、反例、边界与版本。
