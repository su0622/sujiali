# 信息图形数据逻辑与类型案例研究库

本仓库区分两个互相关联但不混同的分类维度：

1. **01-信息图形数据逻辑**：按信息底层组织关系定义类型，回答“数据本质如何组织”。
2. **02-信息图形类型案例**：按视觉表现与传播方式归纳案例，回答“如何把信息转译为视觉叙事”。

## 文档更新机制
新增案例时：①分析案例图及数据；②完成案例报告；③在对应类型说明文档中增加案例链接；④将可复用的共性、原则、制作方法、局限和反例写入总文档；⑤更新修订记录。更新是每次收录时执行的仓库维护流程，并非后台自动运行。

## 证据标记
- **案例观察**：能从已提供图像 / 数据 / 来源直接支持。
- **跨案例原则**：经多个案例比较后归纳。
- **待案例验证的工作假设**：用于指导后续分析，不视为已证实结论。
