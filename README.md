## 收录工作流
1. 核对案例的作者、出处、授权或使用条件；将允许存储的示例图放进对应 `images/` 目录；其他情况保留外部原图链接。
2. 复制同目录报告模板，为每一个案例创建独立的 `案例名信息图分析报告.md`，完整填写六维分析。
3. 确定主类型，可增加次类型与跨目录链接；不要因示例属于 HOW-TO 就默认它只属于一种结构类型。
4. 从新案例中提炼新特征、反例和边界条件，更新对应的「概念及说明.md」及修订记录。该更新需在新增案例时实际执行，并非后台自动运行。
